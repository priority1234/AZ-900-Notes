Azure storage account provides a unique namespace for your storage that's accessible from anywhere in the world over HTTP or HTTPS.
Data is secure, highly available and massively scalable.

When creating an account, you'll start by picking the storage account type. The type determines storage services and redundancy options.

**Storage account endpoints** -

Storage account endpoints are formed of account name and the Azure Storage service endpoint

Storage account names must be between 3 and 24 characters in length. and contain numbers and lowercase letters only.
Name must be unique within Azure.

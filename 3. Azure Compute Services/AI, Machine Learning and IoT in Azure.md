
**Azure AI Services** -

Prebuilt capabilities for common AI usage like language, speech, vision and document processing. Useful to add intelligent features to APIs

**Agentic AI Patterns** -

Combining an AI model with instructions, context and tool use to complete multistep goals.
Built by combining Azure AI Services and Azure OpenAI Service

**Azure Machine Learning** -

Used for building, training and managing custom machine learning models

**IoT and Edge Servcies** -

- Azure IoT Hub enables secure, bi-directional communication between cloud services and IoT devices.
- Azure IoT Central provides a simplified software as a service (SaaS) IoT platform for solution builders.
- Azure IoT Edge extends cloud capabilities to edge devices so some workloads can run closer to where data is generated.

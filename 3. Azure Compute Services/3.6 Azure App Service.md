This is an HTTP based service for hosting web applications, REST APIs and mobile backends. Azure is responsible for management of environment etc.

Build apps, APIs etc in language of choice and host without managing infrastructure.
Offers automatic scaling and high availability. 
Supports automated deployment from GitHub, Azure DevOps etc

**Type of app services** -

- Web apps
- API apps
- WebJobs
- Mobile apps

**Offers -**

- Deployment and management are integrated into the platform.
- Endpoints can be secured.
- Sites can be scaled quickly to handle high traffic loads.
- The built-in load balancing and traffic manager provide high availability.

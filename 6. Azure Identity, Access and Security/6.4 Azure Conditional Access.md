Tool to allow or deny access to resources based on identity signals. Like who the user is, where the user is, what device the user is requesting from.

![](../Static/Pasted%20image%2020260929234028.png)

Useful when - 
1. You could require MFA for admins or for people connecting from outside trusted network locations.
2. Require access to application only from managed devices i.e. a device that meets your standards for security and compliance.
3. Block access from untrusted sources or locations.

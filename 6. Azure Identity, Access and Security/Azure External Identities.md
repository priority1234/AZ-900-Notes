**External ID capabilities**

B2B collaboration - Collaborate with users by letting them use their preferred identity to sign in to you Microsoft apps or other internal apps. Represented in directory as guest users.

B2B Direct connect - Mutual 2 way trust with another tenant. Supports teams shared channels. direct connect users aren't visible in directory, but visible from teams shared channel and can be monitored in teams admin center reports.

Microsoft Entra External ID for customers (formerly Azure AD B2C) - 
Publish custom developed apps to consumers and customers while using Entra External ID for identity and access management

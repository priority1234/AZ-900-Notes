**High Availability -** 99% Uptime. Costs more for more uptime
**Scalability** - Allows easy ability to scale horizontally i.e. add more instances in parallel or scale vertically i.e. add more resources like CPU and RAM.
**Reliability** - With resources deployed in regions around the world, even if one region has a catastrophic event, other regions continue to work just fine which provides reliability.
**Predictability** - Provides performance as well as cost predictability. 
Performance provided by Autoscaling, load balancing and high availability.
Cost provided by predicting the cost spend based on current metrics using data analytics and information.. You can also use price calculators to predict the potential cloud spend before subscribing for a service. 


Cloud allows you to automatically scale resource deployment based on need.
You can configure templates and deploy resources based on that. removing the need for manual configuration each time.
Monitor the health of resources and automatically replace failing resources
Receive alerts regarding cost and performance based on configured metrics

**Management** - You can manage the your cloud environment through various ways -
Through web portal
Using Command Line Interface
Using APIs
Using PowerShell

**Sustainaibility** - You can improve resource utilization by -
Scaling resources down when demand decreases
Turning off resources not in use
Choosing efficient services 
Monitor in real time to track usage trends and optimize according to your use case
